Настройки Telegram

Укажите данные вашего бота для приема отзывов клиники:

Краткая инструкция по созданию бота:
  1. Найдите бота @BotFather в Telegram и отправьте /newbot.
  2. Скопируйте выданный API Token в поле "Токен бота" выше.
  3. Перейдите в свой бот и обязательно нажмите **Start** (/start).
  4. Узнайте свой ID, написав боту @userinfobot. Введите его в поле "ID чата".
